# José Ricardo — Modern Tech Portfolio

Bilingual English/Spanish portfolio built with plain HTML, CSS and JavaScript.

## Open locally
Open `index.html` in Chrome, or use VS Code Live Server. Click **ES / EN** to change language.

## Profile photo
**Action needed:** replace `assets/profile-placeholder.svg` with your uploaded photograph, named `assets/profile.jpg`, then change the `src` of `#profilePhoto` in `index.html` to `assets/profile.jpg`. The placeholder is intentional: no photo was attached yet. Facial features will not be altered without the source photo.

Create a new public repository for this portfolio, upload the files at the repository root and enable GitHub Pages under Settings → Pages → Deploy from a branch.
