## Getting started

1. Install Git and a Java Development Kit (JDK). **Check the actual project configuration for the required JDK version.**
2. Clone the repository:

```bash
git clone https://github.com/RichyTeller/Challenge_Literalura2.0.git
cd Challenge_Literalura2.0
```

3. Inspect the downloaded files. If `pom.xml` exists, import as Maven; if `build.gradle` or `build.gradle.kts` exists, import as Gradle.
4. Find the Java entry point (`public static void main` or a Spring Boot application class) and run it using the project IDE and the correct JDK.
5. If the clone only contains documentation, there is **no runnable application in this repository yet**. Upload the source and build configuration before publishing run instructions.
